## How to run
1. PostgreSQL database `clinic`, user `postgres`
2. `mvn spring-boot:run`
3. App URL: `http://localhost:1014`
4. Import `clinic-quiz.postman_collection.json` in Postman

## Includes
- Full CRUD: Patient, Doctor, Office, Specialization, Appointment
- Quiz Part A (derived), Part B (JPQL joins), Part C (aggregates/bulk)
- Bonus: pagination + JPQL DELETE
